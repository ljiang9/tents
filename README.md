# tents — 帐篷与树(Tents and Trees)谜题生成器与求解器

终端里的帐篷与树逻辑谜题小玩具:随机生成谜题、回溯求解、规则校验,
纯 Python 标准库(`argparse`/`sys`/`random`),Python 3.10+。

## 规则

- 每棵树 `T` 必须恰好有一顶帐篷 `^` 在其上下左右相邻格。
- 每顶帐篷必须恰好与一棵树上下左右相邻(即属于这棵树)。
- 帐篷之间不能相邻,包括对角相邻。
- 每行/每列的数字表示该行/该列的帐篷数量。
- 帐篷总数 = 树总数。

## 用法

```bash
python -m tents                    # 生成一则 6x6 谜题
python -m tents --solve            # 生成并求解,显示答案
python -m tents --size 8 --seed 7  # 8x8,种子可复现
python -m tents --trees 8          # 指定树(帐篷)数量
python -m tents --save q.puz       # 存为文本文件
python -m tents --load q.puz --solve  # 读入并求解
python -m tents --selftest         # 内置自检
```

## 设计取舍

- **生成器保证可解**:先随机放置互不接触(含对角)的帐篷,再为每顶帐篷
  挑选一棵相邻的树(确保该树不与其他帐篷正交相邻),最后由帐篷反推
  行列计数——构造出的帐篷布局天然是谜题的一个合法解。
- **求解器**:MRV 回溯 + 行列剩余计数剪枝;候选格预先过滤掉"与多棵树
  相邻"的格子(帐篷必须恰好属于一棵树)。
- `check_solution` 独立校验全部 5 条规则,生成与求解互相验证。

## 真实验证记录

- `python3 -m py_compile tents.py __main__.py` → 通过
- `python3 -m tents --selftest` → **5 通过,0 失败**:
  - 手工 4x4 谜题(树 (0,1),(2,3),行列计数手工验算)求出唯一解
    `{(1,1),(3,3)}`,与手工答案逐格一致
  - 矛盾谜题(2x2,树 (0,0),计数 [1,0]/[1,0])正确返回无解
  - 20 个种子生成的 6x6 谜题全部可解,且解通过全部规则校验
  - 文本格式存取往返一致
- CLI 端到端:`--solve`/`--save`→`--load`→`--solve`/`--size 3` 中文报错
  exit 2,全部正常

## 已知局限(诚实版)

- 只适合小棋盘(4~10,默认 6);更大尺寸回溯会变慢。
- 生成器**保证可解但不保证唯一解**;求解器只返回第一个解。
- 无交互式填涂,只有"看题 + 对答案"模式。
- 需要终端等宽字体;中文界面。
